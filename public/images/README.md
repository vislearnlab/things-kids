# public/images/

Mascot art used by `index.html`.

## Zorpie

```
zorpie/
├── zorpie_wave.gif           # consent screen
├── zorpie_happy.gif          # how-to-play, breaks
├── zorpie_confused.gif       # mid-game reminders
├── zorpie_stars.gif          # end screen (celebration)
├── zorpie_wave_static.gif    # poster frame fallback
└── zorpie_happy_static.gif   # poster frame fallback
```

Provenance: copied verbatim from
[brialorelle/museumkiosk](https://github.com/brialorelle/museumkiosk)
(the lab's drawing-task / ROAR-style interface). Same mascot keeps the
visual brand consistent across vislearnlab studies.

The `_static.gif` versions are single-frame fallbacks for places where
animated GIFs are awkward (e.g., screenshots, slow connections).

## Why Zorpie and not the previous robot

The first version of this project had a procedurally-generated cartoon
robot ("Beep") drawn with PIL. Bria's feedback during pilot: *"I don't
like the robot — way weird."* Zorpie is the lab's existing well-loved
mascot, kids already know him from the drawing task, and the GIFs are
animator-quality rather than stick-figure.
